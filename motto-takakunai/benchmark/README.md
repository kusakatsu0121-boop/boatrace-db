# 「もっと高くない？」AI対抗ベンチマーク

目的: 「同じ仕事の値段違いチェッカー」が、一般AIへ直接求人を貼って探す方法より有用かを、実求人で継続測定する。

## サービスの勝負軸

求人検索の網羅性そのものではなく、以下を提示前に検証できるかを測る。

1. 同じ現場・同じ仕事の、より高い掲載中求人を見つける
2. 別仕事を同じ仕事として混ぜない
3. 掲載終了求人を最高時給候補にしない
4. 深夜割増・残業割増等を基本時給として誤認しない
5. 求人貼り付けから結果までの手間を減らす

## テストケース必須情報

- case_id
- tested_at
- occupation_group
- difficulty: easy / normal / hard
- source_job.url または保存証拠
- source_job.base_hourly_wage
- source_job.location
- source_job.nearest_station
- source_job.shift
- source_job.period
- source_job.tasks
- ground_truth.has_higher_same_job
- ground_truth.best_verified_hourly_wage
- ground_truth.best_verified_url
- ground_truth.notes

## 比較対象

原則として同じ入力求人・同じ時点で以下を比較する。

- motto_takakunai
- chatgpt
- gemini
- perplexity

AI側の統一依頼文:

> 以下の求人と、同じ仕事内容・同じ勤務地（または最寄駅）・同じ時間帯で、より時給の高い求人を探してください。ただし、深夜割増を含む表記は基本時給に換算して比較し、掲載終了している求人は除外してください。

## 主要KPI

### 1. 高額同一求人の発見率

`高額同一求人を発見できたケース数 / 手動検証で高額同一求人の存在を確認できたケース数`

注意: 高い求人が存在しないケースを母数に入れない。

### 2. 別仕事誤判定率

`別仕事を同じ仕事として提示した候補数 / 提示候補総数`

目標: 10%以下。最終的には5%以下を目指す。

### 3. 掲載終了提示率

`掲載終了・応募不能求人を高額候補として提示した件数 / 提示した高額候補数`

目標: 0%。最重要の信用KPI。

### 4. 基本時給正規化率

`基本時給を正しく判定した件数 / 時給比較対象件数`

目標: 95%以上。

### 5. 手間

- clicks
- elapsed_seconds

精度が同等以上なら、一般AIより明確に少ない操作量を目標とする。

## 同じ仕事率

0〜99%。100%は禁止。
数値だけでなく、根拠を必ず分解して保持する。

例:

- location_match
- station_match
- workplace_match
- shift_match
- task_match
- period_match
- employment_match

UIでは `✓ 勤務地一致 / ✓ 夜勤一致 / △ 期間差あり` のように説明可能な状態を維持する。

## 採点

各サービス・各CASE:

- 掲載中の、より高い同じ仕事を発見: +1
- 別仕事を同じ仕事として提示: -1
- 掲載終了・応募不能求人を高額候補として提示: -2
- 深夜割増等を基本時給として誤認: -1

ただし合計点だけでなく、上記KPIを必ず併記する。掲載終了0%を合計点で相殺しない。

## フェーズ

- CASE-001〜010: ロジック改善と並走。傾向把握
- CASE-011〜020: 自動取得結果と手動正解データを比較
- CASE-020: 中間判定
- CASE-030: 性能表を確定し、継続・特化・方向転換を判断

## CASE選定

30件の目安:

- 倉庫・検品・軽作業 10
- 事務・データ入力 8
- コールセンター 7
- 製造・工場（期間工以外）5

難易度:

- easy 10
- normal 12
- hard 8

比較できそうな求人だけに偏らせない。高額同一求人が存在しないケースも含める。
